Cómo crear una ruta

Tocá el mapa para fijar inicio, puntos intermedios y destino. Después pulsá «Calcular ruta»; cada tramo se calcula respetando los waypoints.

Explorar rutas en otras plataformas

Buscá senderos publicados, compará experiencias y consultá alternativas. Son enlaces externos; TerraAltis no accede a sus bases privadas ni valida automáticamente sus rutas.

Flujo recomendado: consultá la ruta en la plataforma, exportala como GPX si la plataforma lo permite y luego importala con el botón GPX del mapa. La disponibilidad de exportación puede depender de la cuenta.

Funciones útiles evaluadas

  • OsmAnd / Organic Maps: mapas sin conexión. Prioridad alta para una futura descarga de mapas con licencias y atribuciones correctas.
  • Gaia GPS / Locus Map: capas topográficas, relieve y análisis de tracks. TerraAltis ya ofrece varias capas en línea y un perfil estimado; falta validar los datos y mejorar el análisis del desnivel.
  • OruxMaps / Avenza Maps: gestión de tracks GPX y mapas georreferenciados. Importar y exportar GPX ya está disponible; la importación de mapas georreferenciados queda como mejora futura.
  • Wikiloc / AllTrails: rutas existentes con fotos y opiniones. Se enlazan para comparar rutas conocidas; no se copian sus datos ni se supone que una ruta publicada sea segura.
  • komoot / Mapy.com: planificación y perfil de elevación. Sirven como referencia de UX, pero sus algoritmos no reemplazan el motor propio de TerraAltis.
