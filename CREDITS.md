# TerraAltis – créditos y notas
- Mapa: Leaflet (BSD-2). Teselas: OpenTopoMap (CC-BY-SA), OpenHikingMap/openmaps.fr, OpenStreetMap (ODbL), Waymarked Trails.
- Fuentes de capas, uso de OpenRouteService (rutas + elevación) y GPX/perfil: ideas observadas en OpenTopoMapViewer (org.nitri.opentopo).
  No se copió código de esa app; revisá su licencia si querés reutilizar algo más.
- Respetá las políticas de uso de cada servidor de teselas (uso moderado, atribución visible). Para producción, considerá teselas propias o MBTiles offline.
- Rutas: OpenRouteService requiere API key gratuita en Config.kt.
